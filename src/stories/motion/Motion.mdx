# Motion

Motion tokens define **how long** transitions run and **which easing curve** they follow. They complement spacing, radius, and typography: nothing here is raw magic numbers in product code — import from `charte-graphique`.

## Layers

1. **`motionDuration`** — named steps from `instant` through `deliberate` (milliseconds in CSS).
2. **`motionEasing`** — curves for enter, exit, symmetric moves, and emphasis.
3. **`motionPatterns`** — opinionated pairs (`enter`, `exit`, `layout`) used for recipes and real components.

CSS custom properties are available via `motionRootStyleObject()` and `motionDurationCssVar` / `motionEasingCssVar` (prefix `--sparing-motion-`).

## How to use these stories

- **01 Duration** & **02 Easing** — use **Replay all** so every row animates at once; that is the only fair way to compare 150ms vs 200ms or two curves.
- **03 Patterns** — validates **combined** tokens (enter vs exit, layout).
- **04 Components** — modal, drawer, and tooltip; tokens should still feel right on real surfaces.

## Accessibility & tooling

- Stories wrap content with a decorator that respects **`prefers-reduced-motion: reduce`** (transitions collapse to near-zero duration when the user requests reduced motion).
- Visual snapshot tools (e.g. Chromatic) should **pause after animations** or rely on that reduced-motion behavior — animated frames are inherently unstable for screenshots.

## API (quick reference)

```ts
import {
  motionDuration,
  motionEasing,
  motionPatterns,
  motionRootStyleObject,
  motionDurationCssVar,
  motionEasingCssVar,
} from 'charte-graphique';
```

Apply `motionRootStyleObject()` on `:root` or a provider, then reference e.g. `var(--sparing-motion-duration-normal)` in CSS.
