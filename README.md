# charte-graphique

Design system / charte graphique extrait de `@croki-digital/shared-ui`.

## Contenu

- **`src/tokens/`** — couleurs, typographie, spacing, radius, motion, tailles UI, tokens Plexa One
- **`src/theme/`** — thème MUI (`PlexaThemeProvider`)
- **`src/components/`** — composants UI partagés
- **`src/styles/`** — CSS global
- **`DESIGN_SYSTEM.md`** — documentation des fondations

## Peer dependencies

- `react` / `react-dom` ^19
- `@mui/material` ^7
- `lucide-react` >= 0.400

Voir `package.json` pour le détail.
